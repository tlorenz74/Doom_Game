# Doom_Game
A tiny Doom-style first person shooter written in Python 3.13 + pygame. Two levels, no external assets.

## Run
    py -3.13 -m pip install -r requirements.txt
    py -3.13 hellbound.py

## Controls
WASD / arrows: move | Mouse: look | Click or SPACE: shoot | SHIFT: run | TAB: minimap | ESC: pause

## Build the .exe
Run `build_exe.bat`, or push to GitHub and download `Hellbound-windows` from the Actions tab.
